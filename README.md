# Vless_Pool

Каждые 30 минут GitHub Actions собирает публичные VLESS-ключи, **по-настоящему** проверяет каждый
через sing-box (поднимает ключ и делает запрос в интернет, а не просто стучится в порт) и кладёт
рабочие в [`data/good.txt`](data/good.txt), быстрые первыми. Больше двух ключей на один сервер не берётся.

Источники:
- [igareck/vpn-configs-for-russia](https://github.com/igareck/vpn-configs-for-russia) (`BLACK_VLESS_RUS.txt`);
- [tiagorrg/vless-checker](https://tiagorrg.github.io/vless-checker/) (`keys.json`, группы по странам).

## Как пользоваться

Ссылка на готовый список:

```
https://raw.githubusercontent.com/ST3P4P/Vless_Pool/main/data/good.txt
```

Её можно вставить как подписку в NetShift/podkop или в любой клиент, который понимает список `vless://`
по ссылке. На роутере с сервисом `vlesspool` она добавляется в «Источники-списки».

Файлы в `data/`:

| Файл | Что внутри |
|---|---|
| `good.txt` | ссылки `vless://`, по одной на строку |
| `good.tsv` | время ответа (с), `хост:порт`, название |
| `status.json` | когда обновлено, сколько проверено и сколько рабочих |

## Важно

Проверка идёт из дата-центра GitHub, поэтому она показывает, что сервер жив и ключ валидный, но **не
гарантирует**, что он доступен из твоей сети: блокировки провайдера отсюда не видны. Поэтому на
роутере ключи лучше перепроверять ещё раз.

Настройки (источники, группы, лимиты) задаются переменными окружения в `check.sh`. Запуск вручную:
вкладка Actions → check-keys → Run workflow.
